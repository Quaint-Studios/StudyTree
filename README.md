## Overview
StudyTree is an open-source educational application designed to provide structured, interactive learning across all developmental stages: from early childhood fundamentals to graduate-level mathematics, science, languages, and the arts.

## Monorepo Structure
```text
studytree/
├── apps/          # Flutter client, SvelteKit web app, backend api, and shared code
├── curriculum/    # Course modules, lesson markdown, and schemas
├── assets/        # Core media and official branding assets
└── LICENSES/       # All license files (AGPLv3, CC BY-SA 4.0)
```
